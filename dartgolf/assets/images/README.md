# Grafiken

Dieser Ordner ist bewusst leer.

Die Bahnen, der Ball, das Loch und alle Effekte werden in `<canvas>` gezeichnet
(`src/game/game-engine.js`). Es werden keine fremden Grafiken, Marken oder
Bahnlayouts verwendet.

Eigene Bilder (z. B. Hintergründe oder Dekoration) können hier abgelegt und in
den Bahndaten referenziert werden. Bitte nur eigenes oder nachweislich frei
lizenziertes Material verwenden.
